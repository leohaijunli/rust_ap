长尾背景：712 s 断电会话曾出现 1 次 **152 ms**（A1 卡特征，与 PX4 文档"多数卡每分钟多次数百 ms 停顿"同型）；按工程师裁决以队列扩容缓解，r3 复测窗口达标。卡本身按 PX4 逐卡写尖峰判据仍未达"可靠卡"档（Extreme U3 级），换卡是未来进一步压长尾的零代码手段（[对照](../logging-dropout-options.md)）。

## 如实记录的边界

1. **自动重启的板载目击未捕获**：写失败自动换文件（3 次/500 ms 退避）已实现并上板（host 用例覆盖判定逻辑；300 s r3 全程在新固件上运行），但三次拔卡尝试均被实验台 USB 扰动打断（板子掉电重启，监控失效）。该目击留待实验台 USB 固定后补验；不影响窗口判定（分布与 Error 路径均已实测）。
2. 拔卡后 `<1 s` 的瞬时缺卡会被完全吸收（0 写失败，实测两次）；`<`flush 间隔的缺卡对日志不可见。
3. id 27/30 的大文件仅做头部 2 MiB 解析 + 目录项大小核对，未全量下载（115200 波特率全量需 6+ 小时）。
4. 未实现（与 PX4 的已知差异）：日志轮转/空间清理；`sd_bench` 等价选卡诊断（可选，未排期）。`LOG_CAN_HZ` 降速杠杆保留。

## 判定

**H-04 通过**（按 ≤10 ms/事件 0 窗口；分布、断电、缺卡、拔卡 Error 路径均有板载证据）；上述边界随记录移交 M1/PL-a 复验范围。
