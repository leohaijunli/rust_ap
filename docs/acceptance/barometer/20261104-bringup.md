# BMP388 板载气压计：软件与首次读取

2026-11-04。**驱动及首次真实读取通过；完整 BARO-01～04/E7 尚未通过。** MAVLink/ULog 实物字段/速率、参考精度与一次失效恢复仍待验；当前先处理共享栈余量问题。

## 契约与实现

- 固定 PX4 `d6f12ad1c4f70ad3230afd7d86e971421e02fef4` 的 FMUv6X Rev 3：内部 I2C4，SCL PF14 / SDA PF15，地址 0x77，PG8 使能 sensors4。先识别 ID=0x50 再对 BMP388 发软复位；不对 ACK 但 ID 不符的器件写配置。
- `src/core/bmp388.rs`：21 B 小端有符号 trim、CRC-8/0x1d、P/T 24-bit ADC、固定 PX4 整数补偿；i128 扩大中间项范围，保留逐次整数除法。压力 Pa、温度 °C，非法/未 ready/传感器错误拒绝；200 ms 后陈旧。
- `src/drivers/barometer.rs`：压力×16、温度×2、IIR off、forced，43.3 ms 转换上界；未 ready 最多再等 10 ms。I2C4/BDMA 不能访问当前 AXI DMA 缓冲，采用 HAL 10 ms 超时的 blocking I2C；记录真实事务耗时。高优先级 IMU 不在该线程执行，未宣称 async 可抢占所有同步等待。
- 每次配置回读、trim CRC 校验，失败撤销最新快照并 500 ms 后重新识别/配置；不反复切共享 PG8 电源。输出标准 `sensor_baro`（payload 32 B），`LOG_EN_BARO/LOG_BARO_HZ` 默认 1/10 Hz；MAVLink 压力用 hPa，`SCALED_PRESSURE` 单独温度，HIGHRES_IMU 不用气压计温度覆盖 IMU 温度。
- pressure altitude 使用标准气压基准，仅为气压观测，非测绘/GNSS MSL。独立 EKF baro API 不推 mag 缓冲；缺失磁力计保持缺失。
