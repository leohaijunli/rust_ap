# E6-H：独立无 GPS 与标准输出

日期：2026-11-04。**本地软件门通过，新增 CI 待执行。** 固定 PX4 v1.17.0 `d6f12ad1c4f70ad3230afd7d86e971421e02fef4`。E6-H 只验 host 实例与数据边界；随后工程师授权回装普通 H7 合并包，但仍没有板载 EKF 或真实 GNSS/雷达/气压/磁场资格。E7 依赖保持 M1、P6a、P4b-g、P2、PL-b。

## 结果

两种合成模式各 5 s 暖机 + 60 s 场景、400 Hz / 26000 IMU 输入、20 Hz / 1300 发布；输入含 5°/s 偏航及 0.05 m/s² 北向加速度。姿态对准后才发布，全球/局部 MAVLink 按有效性停发，不填伪零。

| 项 | 无 GPS | 主 GNSS |
| --- | --- | --- |
| ULog dataset | 8 个，multi_id=1 | 12 个，multi_id=0 |
| 姿态/角速度日志 | 各 1158 条 | 各 1158 条 |
| 局部 / states / status 日志 | 各 1300 条 | 各 1300 条 |
| 全球位置日志 | **0，禁止订阅/发布** | 1091 条 |
| aid 原始诊断核对 | 3888 条 | 4809 条 |
| MAVLink | ODOMETRY 1158、ESTIMATOR_STATUS 1300 | ATTITUDE_QUATERNION 1158、LOCAL_POSITION_NED 1091、GLOBAL_POSITION_INT 1091、ESTIMATOR_STATUS 1300 |
| 运动真值最终水平误差 | 69.20386 m | 0.51954 m |
| 标准局部日志最终水平 σ | 349.31622 m（核心条件化 P） | 0.23212 m |

固定 9 份 `.msg` 的 **165 个运行字段**与对应 12 个 format，经 pyulog 1.3.0 / pymavlink 2.4.49 独立解析。完整字段顺序、类型、数组、时间、FRD/NED、SI/整数缩放、有效位、P/复位映射、MAVLink CRC/序列回绕均核对；整数时间/标志严格相等，f64 经纬度绝对容差 1e-10°。原始 PX4 文件逐项核对及 hash 见 [schema 证据](20261104-e6-schemas.json)。

### 漂移与 σ 的含义

同样 IMU/baro/mag/range 可对应真实北向加速，也可对应静止平台上随偏航旋转的加计偏置；无水平观测不能区分。60 s 自由积分 `0.5×0.05×60²=90 m`，当前无 GPS EKF 的运动误差 69.20 m，与理论量级一致；静止偏置解释下误差 32.94 m。PX4 内部伪位置约束和倾角/零偏估计会改变输出，**没有修改核心来强求误差恰为 90 m**。

无 GPS 的 xy/v_xy 无效、没有全球参考；独立 ODOMETRY 水平位置/速度方差为 `+INFINITY`、quality=0，垂直有效时保留有限 P。1158 条输出的无界 3σ 全部覆盖运动误差；这只证明没有输出过度自信的有限精度，**不是有限精度、NEES/统计一致性或实物导航通过**。标准局部日志仍按 PX4 发布核心 P 和无效位；更强水平约束及有限 σ 资格留后续。

## 实现与必要检查

- `NoGnssEkf` 独立拥有核心/延迟缓冲，只接受 IMU/baro/mag/range。GNSS 输入编译失败；主实例坏 GNSS 后，独立实例的完整状态/P/输出与另一独立基线逐步相等。不是故障域隔离：panic=abort 仍会停止整个应用。
- 标准快照一次取走角速度/加速度累加器，ULog/MAVLink 共享同一份；状态维度 25、P 对角 24；记录真实复位，不用名义 xy 的零值替代位置累积。未知 LPF、观测/设备/模块统计按 [字段约定](../../message-contracts.md#e6-h-estimator-边界) 保留 NaN/0，不冒充已计算量。
- 41 项相关 Rust（含 2 项 MAVLink）、1 项编译失败、9 项 Python 通过；既有 ULog 4 项也通过（另有 3 项 estimator ULog 已含在上述 41 项）。host 与普通 H753 Clippy、fault-dump 配置 Clippy、fmt 通过；没有扩大到全覆盖/蒙特卡洛或新增 C++ 对拍，E1-H～E5-H 数学黄金结果复用。
- 独立 estimator 注册表 main id=11–22、独立实例 id=23–34；format 使用调用方 2048 B 缓冲。现有固件仍 11 topic、runtime record=152 B、队列=168 KiB；新 local/status/states payload=192/129/213 B，**未直接塞入固件队列**，E7 必须先落实预算/调度/参数/回退。
- 本地普通 E6-only 隔离构建：source=`fddd7be76a0075fb`，raw/padded=`410672/410688 B`，static RAM=`268680 B`。随后按工程师要求合并 PX4IO/logger-switch/其他工作后再验普通包：source=`c6fe90f898b68f8f`，raw/padded=`426488/426496 B`，static RAM=`269856 B`，余量 `187872 B`；入口 `0x08020000`、board ID 53、64 KiB 共享栈 / 1 KiB 故障栈与 ELF/bin/PX4 一致性通过。该普通包随后上传/校验并回读成功；**EKF 任务仍未启用**，PX4IO 实物通信 Timeout，见[单独回装记录](../px4io/20261104-merged-flash.md)。
- `code-simplifier` 局部审视后，独立实例复用核心 reset/配置，不重复保存参数；全球参考使用成对 Option，保持行为与错误语义。并行的 PX4IO/logger-switch 结果另见[记录](../px4io/20261104-host.md)。

## 历史失败与修复

1. 首次测试未显式选 host target，工程默认 thumb 无 test/std；改用 `x86_64-pc-windows-msvc`，不改工程 target。
2. 启动即注入偏置的静止测试只产生 0.00846 m 偏移，不能证明自由积分 90 m；保留该事实，改为暖机后注入，并明确两种不可区分真值。映射单测另显式构造对准位，不把单测 fixture 当对准资格。
3. pyulog 默认取 multi_id=0，独立实例为 1；解析改为先验证唯一实例再选 dataset。初版比较器还错误假设合成 GNSS 永不出现 glitch，现逐项对照原始 aid ratio，不隐藏真实拒绝/状态位。
4. host 支持 `f32::rem_euclid`，no_std 不支持；改用共享 libm fmodf。整数比较不使用相对浮点容差，f64 坐标另设严格容差，新增失败回归。
5. 仓库内隔离工作树继承父子 `.cargo`，导致 `-Tlink.x` 重复；仅本次隔离构建显式 `RUSTFLAGS='-C link-arg=-Tlink.x'`，未改 linker/分区。Python 3.10 报告进程临时映射已安装 tomli 并加入 tools 模块路径，未改项目依赖；隔离 lib 注册顺序经 fmt 修正后重新构建。
