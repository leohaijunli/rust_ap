# 板载 BMM150 → 主 EKF2：软件交付

日期：2026-11-07。工程师要求新增板载地磁驱动并送入滤波器。本轮没有烧录、设参/保存、清故障或解锁；**不代表板载磁融合/航向资格通过**。

## 实现与来源

- 固定 PX4 v1.17.0 / `d6f12ad1c4f70ad3230afd7d86e971421e02fef4`：Rev 3 BMM150、I²C4/0x10、rotation=0、高精度 20 Hz；寄存器和补偿来源及内/外磁源机制见[地磁说明](../../magnetometer.md)。C++ 参考只在 host 运行，板上保持纯 Rust/Embassy。
- `src/core/bmm150.rs`：13/15/14-bit ADC 解码、trim 补偿、µT→Gauss；非法 trim、溢出、RHall=0 和陈旧数据拒绝。`src/drivers/magnetometer.rs`：唤醒后确认 ID=0x32，再软复位、自检、配置/周期回读；失效停止发布、500 ms 重试。
- `main.rs` / `barometer.rs`：BMM150 与 BMP388 共用同一 I²C4，事务借用不跨 await，PG8 由主任务持有；恢复不切断共享电源。未引入新 DMA/unsafe、堆或外接磁源投票。
- 复用 `submit_measurement(Measurement::Mag, device_id)`。标准 `sensor_mag` / `vehicle_magnetometer`、`HIGHRES_IMU` 磁场与健康位、`!mag` / `EKF2_MAG` 诊断；工厂 trim 不等于安装硬/软铁校准，温度未知为 NaN。
- `LOG_EN_MAG` / `LOG_MAG_HZ` 追加在原 165 项后，新目录 167 项；原 ID/值/类型不变，FRAM 仍为原双 1024 B 槽。新增日志至多约 1.66 kB/s，runtime 记录仍适配 218 B 槽；未重排旧 topic ID。
