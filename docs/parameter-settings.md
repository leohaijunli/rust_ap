# 参数设置说明与审核结论

更新：2026-11-07。当前软件目录 167 项：原 165 项值/类型/顺序不变，板载地磁新增 `LOG_EN_MAG` / `LOG_MAG_HZ`，追加在已有 ID 之后；FRAM 存储布局不变。本说明不代替台架或飞行资格。

## 如何读参数说明

| 标记 | 意义 |
| --- | --- |
| 只读（1 项） | `MAV_SYS_ID` 当前固定 1；拒绝修改 |
| 已接入（24 项） | 日志、状态灯、估计启用/选择或遥测速率有实际消费者；不保证相关实物当前可用 |
| 已接入配置（24 项） | EKF2 运行时读取该值；相关算法运行且重配置成功后使用 |
| 条件生效（54 项） | 配置已读取，作用依赖观测、模式、地效/地形或状态；部分磁场/地形参数也参与预测，不是整组都等到传感器融合才使用 |
| 未接入（64 项） | 用户值可读写/保存，但运行时不读取，不能靠调此值改变算法；有的路径仍使用固定 PX4 默认值 |

EKF2 的 78 个配置键由真实 `Params::maps()` 导出，不用旧的 `Support::Planned` 标签推断。固定 PX4 的短说明和枚举/位含义只作为参考，不能据此宣称全部 PX4 功能已实现。

## 易误用的设置

- `EST_EN=0/1` 停止/启用**数据估计**，不解锁；`EST_ALGO=0/1` 请求 Mahony/EKF2，还受 `EKF2_EN`、构建类型和实际回退影响。用 `!ekf2` 核对实际选择。
- `LOG_EN_*` 只关闭/允许某组 SD 记录，不是启动/停止 logger，不停止传感器或估计器。仍需显式启动 logger。
- `LOG_*_HZ` 是记录上限，不提高源采样率。CAN 组涵盖 ESC/GNSS/CAN 统计；节点状态、参数变化归事件组。提高频率会增加 SD/队列压力；通常保留事件记录。
- `LOG_EN_MAG=1` / `LOG_MAG_HZ=20` 为新软件默认值，控制 `sensor_mag` / `vehicle_magnetometer` 记录上限；不改变磁融合开关。`EKF2_MAG_TYPE` 控制融合模式，不是板载/外接选择器。当前只接板载 BMM150，未实现安装后硬/软铁校准或外接自动切换，见[地磁说明](magnetometer.md)。
- `MAV_RATE_*` 只改变两链路默认发送速率，不改变采样/融合频率。511 的链路覆盖优先；GPS 无数据时 NO_GPS 仍最多 1 Hz，电源高频发送可能重复最新测量。
- `MAV_RATE_HB=0` 会关闭心跳/系统状态/UTC 组，可能影响 QGC 连接及依赖心跳的升级预检；正常联机不建议关闭。
- `LINK_LED_HZ` 是状态/以太网灯闪烁频率，不是控制频率或 IO 安全灯命令。
- EKF2 位掩码按位相加。例如 `EKF2_IMU_CTRL=7` 是 1+2+4；`EKF2_GPS_CTRL=7` 是经纬度/高度/速度三项。航向位 8 当前不支持，运行时拒绝它，即使目录最大值仍为 15。
- `EKF2_GPS_MODE` 当前仅接受 0；`EKF2_MAG_TYPE` 当前接受 0/1/5/6；高度参考的视觉源没有实物实现。参数允许值与数据源真实可用是两回事。
- 任何被接受的 EKF2 目录项改动都可能重新初始化估计器，**包括未接入项**。参数回显、发生复位或保存成功都不证明该项正在被算法使用。

## 回显、生效与保存

1. QGC 的 PARAM_VALUE 来自飞控当前 RAM 值；元数据里的 default 只是缺省参考。
2. 参数目录的 min/max 不等于推荐飞行调参范围；运行时还校验支持的模式和组合，拒绝时回显原值。
3. QGC 的被接受设值沿用静默窗口延迟保存；持久化只在 disarmed/输出关闭时执行。`!params` 的 dirty/pending_save/last_error 用于核对保存，不把回显当成已落盘。
4. 本轮不改变算法或自动设参/保存，不自动烧录。新文案需新固件中的元数据文件；CRC 更新后重新连接/获取元数据，不能只刷新旧固件的缓存就期待新说明。
