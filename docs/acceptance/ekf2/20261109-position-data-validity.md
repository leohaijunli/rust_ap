# 位置数据有效性与飞行资格拆分

日期：2026-11-09。工程师已在 CAN1 看到健康 GPS_RAW_INT，要求拆开“数据有效性”和“飞行资格”，完成后推送。本轮只做软件发布层、诊断及相关验证，不自动回装；原板载 `32269dec1d8137b4` 保留旧位置发布门。

## 实现边界

- `product::snapshot` 不再因飞行资格未验就强制清零水平位置/速度、删除全球位置。位置/速度/原点与解算标志来自原核心，仅当选用健康 Filter 且运行时数据新鲜时保留；不强设有效、不复制 GPS_RAW_INT、不改估计数学/质量或 CRC 门。
- 同一非创造性数据门也用于板级 `latest`：慢发布缓存尚新鲜但快速姿态已陈旧时，不借用旧 EKF 位置。停用/Mahony 回退/陈旧清除位置及预测位置状态位；既有高度/姿态/复位语义保留。
- `LOCAL_POSITION_NED` 仍要求位置/速度各轴有效且有限；`GLOBAL_POSITION_INT` 仍要求真实全球原点、经纬度/高度和速度有效。没有满足条件就不发，不为“看到消息”填零。
- `heading_good_for_control=false`、原解锁/非零输出拒绝与阶段门不变。`EKF2_RUNTIME nav_qualified=false` 保留为飞行导航资格的兼容字段；新增 `EKF2_DATA_VALIDITY` 分别显示局部/全球位置、速度有效位和 `flight_qualified=false`，只读借用已有快照、不二次采样积分。
- MAVLink/ULog 共用这一份快照，现有速率/日志开关不改；对外数据有效不是飞行放行。实际 GNSS 融合、标定/精度、RTK、中断恢复及控制仍按原阶段验收。

## 必要软件验证

- 新合成场景为静止 IMU 1 kHz、baro/mag 20 Hz、GNSS 5 Hz、8 s；仅测试将 GNSS 健康保持改为 1 s，生产参数不变。核心局部/全球位置先已有效，旧产品发布门导致回归失败；修复后数据与核心逐字段一致，LOCAL/GLOBAL MAVLink 可构建，但控制航向仍禁用。
- 同例覆盖陈旧 5001 µs、慢缓存有效性撤销、超时降级/Mahony 和 disable；既有无 GPS/仅 baro 用例继续检查不伪造水平/全球解算。
- 测试初始化先因 MagSample 必须显式 reset、无 Default，以及 GlobalPosition 无 PartialEq 编译失败；按现有 DTO 补字段/逐字段比对修正，未改 DTO 或生产算法来迁就测试。
- 相关产品 3 项 host、MAVLink 映射 2 项、fmt、host 库/测试与普通 H753 Clippy 通过；一次局部 `code-simplifier` 审视完成，数据门只提取为两个实际调用者共享的实现，诊断借用快照而非反复复制。不重跑未受影响的全库数学对拍。
- 不借用之前 CAN1 CRC/抢占结果声称新位置发布已上板。
