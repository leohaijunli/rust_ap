## 重现

在已配置的 Ubuntu/WSL shell 中运行；Windows 可直接运行 `check_ekf2_imu.py` 复验 Rust 对拍：

```sh
python3 tools/gen_ekf2_covariance.py --root /home/dev/PX4-Autopilot --check
python3 tools/golden_cpp/build.py --root /home/dev/PX4-Autopilot
python3 tools/check_ekf2_imu.py
python3 tools/check_ekf2_host.py --case imu_noisy_clipped --output target/ekf2-host/noisy-check
python3 tools/check_ekf2_imu.py --baseline tests/data/ekf2/imu_noisy_clipped --output target/ekf2-host/rust-noisy
```

输出为忽略的 `target/ekf2-host/{rust-imu,rust-noisy}/report.json`。Rust standalone dump 只创建新文件；资格脚本用独立临时目录再替换派生输出，不覆盖原输入或黄金文件。

## 边界与历史失败

E1-H 从已有积分 DTO 开始；没有真实 8 kHz 输入桥、低延迟输出预测器、完整五传感器融合、板载参数桥或 Mahony 回退。原版 `core_imu` 默认 `in_air` 标志只是参考配置，不是本板飞行/解锁事实；无外部观测时不得把位置/高度或绝对 yaw 发布为有效导航。

初次生成遇到 C++ 跨行表达式解析与非 login WSL 的 rustfmt 路径问题，已用严格语法转换和已配置 shell 修正。首次 H753 构建拒绝 `f64::rem_euclid`，改为原版 `floor` 包角公式后通过；未改上游数学表达式或放宽对拍容差。局部简化复用同一个基向量 Joseph 更新，移除重复平方包装，未扩改无关实现。
