## 历史失败与边界

- 初始磁表达式生成误取 C++ 指针别名赋值，又遇到符号表达式括号替换；限定赋值匹配与平衡表达式后通过，加入对应回归用例。
- 原 5–6 s `baro_mag_dropout` 数值回放通过，但磁融合直到约 8.15 s 才首次启动，不能验证磁停止。该场景原样保留，仅作气压中断历史结果；新增 12 s 对准后中断，不覆盖旧数据。
- 中断对拍发现遗漏垂直 dead-reckoning 超时，以及磁停止误用 500 ms、未复位磁协方差/撤销 yaw。按原版 1 s 时间门和状态机修复后通过同一黄金数据，未调整门限。
- 新 lint 的索引循环改为等价 enumerate；源码变动后的旧 ELF 被 build report 的 source-ID 检查拒绝，重新构建/打包后通过。遥测账本从技能启用时开始，历史耗时不补造。
- 输入是压力高度与校准后的 FRD/gauss 磁场，不是实际 BMP388/BMM150 数据。未接入完整 `NavFilter`、GNSS/WMM 位置驱动、所有高度参考分支、板载参数/8 kHz 输入桥或 Mahony 回退；相关资格仍归后续阶段。
