# H-04 SD 卡日志基线（32 GB 普通卡）

日期：2026-11-07。范围：一次 65 s 零输出正常日志采集、只读下载与解析。未设参/保存、未启用非零输出、未做受控断电或拔卡；**不代表 H-04 通过**。

## 条件

- 卡：32 GB 普通消费卡，无 A1/A2 或工业 pSLC 标注；具体品牌/型号仍待工程师读卡面。
- source=`a17a2d35bab6f05a`，COM4，disarmed；`logger start/sync/stop` 均 `accepted=true`，结束后 status=Disabled。
- 采集前后 165 项参数逐项一致；没有写参数、清故障或重启。

## 判定边界

- 这是一次基线，不是写延迟分布；还需要更长或多次采集、受控断电以及缺卡/拔卡，才满足 H-04 原范围。
- 当前卡不满足 H-04 的 A1/A2 或工业 pSLC 选型判据。即使本次时序未超标，是否继续用此卡需工程师决定。
- 允许丢失窗口尚未给出。可用的实测上界：单次最长 5 ms、正常丢失 0.026%/65 s、事件丢失 0；事件丢失按既有要求保持 0。
- 单位：ULog dropout 的原始 `duration` 单位是 ms（ULog 规范与 `ulog::dropout(duration_ms)`）。本记录直接使用原始值；`analyze_dropout.py` 当前显示会再除以 1000，不能把显示值直接当毫秒阈值。
